This distinction prevents an apparently precise 3D object from being mistaken for an official building, parcel, or legal property record.

## 4. Source availability log

The official IIT Patna Annual Reports index is available and lists the 2015–16 English report. The supplied IWD Academic Area URL and both supplied annual-report PDF paths returned the IIT Patna website’s 404 page in the validation environment on 24 August 2026. The project therefore retains a **source-cited** rather than **independently document-verified** status for the Academic Block-4 text. The evidence tier can be upgraded only when IIT Patna restores a retrievable original document or an unaltered official report page is supplied.
